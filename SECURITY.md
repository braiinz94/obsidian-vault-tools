# Sécurité

Merci de ne pas ouvrir d'issue publique pour une faille. Utilisez le signalement privé de GitHub : onglet **Security** du dépôt, puis **Report a vulnerability**.

Indiquez la version, la commande lancée et, si possible, un petit coffre d'exemple qui reproduit le problème. Ne joignez jamais de notes personnelles.

Périmètre utile : écriture hors du coffre, perte ou altération de contenu, exécution de code via une note ou un fichier de configuration, déni de service sur un coffre piégé.
